index.html — клиентская часть (для проверки работы)
server.js — серверная часть (для отображения всех выполненных действий) 
Для начала работы необходимо выполнить следующие команды: npm install — для установки зависимостей
npm start — для запуска сервера (иначе на клиенте возникнет ошибка из-за отсутствия подключения к серверу)
