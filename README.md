index.html - клиентская часть (для проверки работы)
server.js - серверная часть (для отображения всех выполненных действий)
Для старта работы необходимо выполнить следующие команды: npm install - для установки зависимостей
npm start - для запуска сервера (иначе возникнет ошибка на клиенте, из за отсутствия подключения к серверу)
